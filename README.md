Core App Experience

AWAKEN transforms everyday life into a dark fantasy RPG progression system where users become the main character of their personal journey. Users create and complete daily, weekly, and main quests based on real-life goals, earning experience points (EXP) to level up, advance through hunter ranks, develop skills, improve attributes, and unlock achievements.

The app features a personalized dashboard displaying hunter status, EXP progress, active quests, and life statistics. A quest management system tracks tasks and milestones, while skill trees encourage continuous learning in areas such as software development, English communication, health, discipline, and problem-solving. Dedicated life goals help users monitor financial progress, prioritize family, maintain well-being, and pursue long-term dreams.

AWAKEN combines immersive dark fantasy visuals, rewarding progression mechanics, and practical productivity tools to encourage consistency without promoting burnout. Every action contributes to personal growth, and every completed quest brings users closer to the person they want to become.

Core loop: Set goals → Accept quests → Take action → Earn EXP → Level up → Develop skills → Achieve real-life milestones.
